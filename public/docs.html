CAPTCHA Protection

GET/captchaHow To Use CAPTCHA

Simple steps to install and use the CAPTCHA widget on your site.

Step 1 — Install Script

HTML
<script src="https://YOUR-RAILWAY-URL/widget.js"></script>

Step 2 — Add Container

HTML
<div id="captcha-box"></div>

Step 3 — Render CAPTCHA

JavaScript
Captcha.render("#captcha-box");

CAPTCHA Types

codedefaultRandom 6-character code challenge.
puzzleinteractiveSlide puzzle piece to fill the gap.
buttonsimpleOne-click browser fingerprint check.

With Options

JavaScript
Captcha.render("#captcha-box", {
  type: "puzzle",   // code | puzzle | button
  lang: "en",       // en | ar | fr | de
  size: "medium",   // small | medium | large
  onVerify: function(result) {
    console.log("Token:", result.token);
  }
});
POST/api/captcha/generateGenerate Challenge

Create a new CAPTCHA challenge token. Send this token to your frontend to display the widget, then verify it after the user solves it.

Request Body

typestringcode | puzzle | button | grid. Default: code
langstringen | ar | fr | de. Default: en
themestringdark | light | auto. Default: dark
sizestringsmall | medium | large. Default: medium
cURL
curl -X POST https://YOUR-URL/api/captcha/generate \
  -H "Authorization: Bearer desv_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type":"puzzle","lang":"en"}'

Response

200 OK 
{
  "success": true,
  "challenge_token": "chk_abc123xyz",
  "type": "puzzle",
  "lang": "en",
  "expires_in": 300
}
POST/api/captcha/verifyVerify Solution

Verify that the user solved the CAPTCHA. Call this from your backend after the user submits the form.

Request Body

challenge_tokenstringToken returned from /generate. Required.
solutionmixedtrue for puzzle/button, 6-char string for code type.
cURL
curl -X POST https://YOUR-URL/api/captcha/verify \
  -H "Authorization: Bearer desv_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"challenge_token":"chk_abc123","solution":true}'

Response

200 OK 
{
  "success": true,
  "verified": true,
  "token": "cap_x82j9kl3m",
  "message": "CAPTCHA verified successfully."
}
GET/api/captcha/status/:tokenToken Status

Check the current status of a challenge token.

cURL
curl https://YOUR-URL/api/captcha/status/chk_abc123 \
  -H "Authorization: Bearer desv_live_YOUR_KEY"

Response

{
  "success": true,
  "status": "pending",  // pending | solved | expired
  "type": "puzzle",
  "expires_at": 1717000000000
}

API Key Authentication

All requests must include a valid API key in the Authorization header.

Authorization: Bearer desv_live_xxxxxxxxxxxxxxxxxxxx
Never expose your API key in client-side code or public repos. Use environment variables.

Getting Your API Key

1
Create a project

Deploy this project on Railway and set API_KEY in environment variables.

2
Set your key

In Railway dashboard → Variables → add API_KEY=desv_live_YOUR_SECRET.

3
Use in requests

Add Authorization: Bearer YOUR_KEY header to every API call.

4
Test first

Use key desv_test_demo_key_99999 for development — always passes, no real validation.

Key Types

Live vs Test Keys

desv_live_…LiveReal validation. Use in production.
desv_test_…TestAlways passes. Safe for dev/testing.

Authentication Errors
